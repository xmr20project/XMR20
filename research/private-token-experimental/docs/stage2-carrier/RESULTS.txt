================================================================================================
A. WHAT CHANGED
================================================================================================
The lab's implicitly funded relay path is gone. The holder's extension now: scans its own XMR
outputs (view key, local RingCT index count, key-image spent tracking); quotes the exact network fee
BEFORE proving (monero-oxide weight model, daemon fee rate); shows it for approval (Approve/Cancel);
proves the record; builds and signs the ordinary Monero carrier (16-ring CLSAG, Bulletproof+, the
record in tx_extra, change to itself plus a wallet2-like 0-amount dummy output); publishes it to the
daemon directly; pays the fee from its own XMR. The test backend has no relay process and no relay
action; it refuses any field named like a key image, carrier, blob, ring or record wire; a labelled
TEST SERVICE `fund` action mines coinbase rewards to the holder's public Monero address so the
synthetic wallet has XMR at all. Everything secret (Monero spend/view keys, owned outputs, input
selection, decoy sampling, signing) runs inside the holder's wasm; the worker only performs daemon
RPC calls (holder-carrier.js). monero-wallet (monero-oxide 0.2.0, vendored locally) is compiled into
the holder wasm (now 5,032,305 bytes).

D. FEES: OFFLINE CHAIN vs MAINNET (not an estimate)
================================================================================================
Fakechain dynamic rate 1,200,000 piconero/byte -> 0.003024 XMR per 2,520-byte carrier. Mainnet rates
come from the node at send time; at an illustrative 20,000 piconero/byte the same carrier would cost
50,400,000 piconero (0.0000504 XMR). The popup shows the real quote and the labelled illustration.
Consolidation: merging n notes into one needs ceil((n-1)/2) carriers, each with its own fee (shown).

================================================================================================
E. FAILURES FIXED (stage 2) AND REMAINING BLOCKERS
================================================================================================
Fixed: synthetic roots not reduced mod l (reduce; identity for real keys); `ProvidesUnvalidatedDecoys`
import; the first carrier shape paid 0.000001 XMR to itself and the dust was later picked as an input
(NotEnoughFunds) -> wallet2-like 0-amount dummy output + minimum-input rule + precise error; unlock
rule one block stricter than monerod -> aligned; test expectations (largest-first selection, change
lock, refusal text); process hygiene (two test runs started at once collided on ports/log).
Open: mainnet fee/decoy behaviour unmeasured (offline chain; publish uses do_sanity_checks:false
because the fakechain's ring statistics fail monerod's sanity check); change-chain linkage and the
carrier's extra-size fingerprint are inherent and only documented; a holder with a single XMR output
can send one carrier per 10 blocks; no relay means holders without XMR cannot transact (product
decision); everything else from stages 0-1 (disposable setup, no audit, bridge finality, trading).
