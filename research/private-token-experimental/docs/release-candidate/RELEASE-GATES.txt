OPERATIONS (what must exist before any real-funds pilot; none exists as a deployable component today)
  monitoring        supply vs backing invariant per asset every block; nullifier double-admission alarm; parameter manifest
                    hash check at every role start; node agreement monitor (primary vs observers) with alert on divergence.
  reconciliation    daily: operator journal vs indexer replay vs Solana receipts; every burn either pending, paid once or
                    orphaned with an incident; every credit either indexed or orphaned.
  key custody       issuer key: HSM/threshold with audit log (review/08 R5); operator payout key: separate, limited balance;
                    release manifest signing: threshold of release keys. Nothing here uses a production key today.
  incident stops    (already in the lab) operator halt on paidWithoutBurn / accepted-prefix change; wallet refuses new signing
                    after an incident; manual restart only; no automatic re-enable.
  recovery          wallet: phrase restores notes and balances (verified); pending journal is per installation (documented).
                    operator: journal restore from backup + replay; corrupted journal refuses to open (test in this candidate).
                    indexer: stateless replay from the pool start height.
  upgrades          reverting SOFTWARE is always possible; reverting on-chain actions is not: a published record, a paid
                    payout, a broadcast carrier are irreversible. A new circuit/parameter set is a NEW LEDGER DOMAIN and
                    therefore a migration event (claim/boundary), never an in-place patch.

STAGED ROLLOUT (recommendation; only after the gates above)
  1. Private transfers on mainnet with a REVIEWED multi-party parameter set, real but small balances, no bridge, no trading:

     under the adopted finality policy with reserve and clawback escrow (E11, E12, D). 4. Trading: only if a product decision
     funds a settlement construction and it passes review; otherwise stays off the private format.
  Plainly: today transfers work on stagenet; bridging payouts and trading are blocked; the complete product is not ready.
